Drop the official Palo Alto Networks logo here as `panw_logo.png` (PNG, ~160px wide works well).

The dashboard looks for dashboard/assets/panw_logo.png and displays it in the header.
If the file is not present, it falls back to a styled "paloalto NETWORKS" text wordmark,
so the app still runs without it. (The logo image is not bundled, to respect PANW's brand
assets — download it from paloaltonetworks.com/company/brand or your internal brand kit.)
